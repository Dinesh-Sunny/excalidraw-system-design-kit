# Security policy

The kit is a static Excalidraw library file plus a static website. It runs no server and stores no user data.

## Reporting a problem

If you find something that could put users at risk, such as a library item that carries an unexpected link or the website loading something it shouldn't, please report it privately with GitHub's [private vulnerability reporting](../../security/advisories/new) instead of opening a public issue.

You'll get a reply within a few days, and a fix is shipped in the next release.

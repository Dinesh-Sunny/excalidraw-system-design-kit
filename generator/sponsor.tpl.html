Questions

Will the kit stay free?

Yes. The kit is MIT licensed and always will be. Sponsoring never locks anything away.

Can my company get an invoice?

Yes. Sponsor from your organisation's GitHub account and GitHub handles receipts and invoices for you.

Which logo do you show?

Your GitHub organisation's avatar, linked to your website (or your GitHub page). Change your avatar on GitHub and the site updates within a day.

Where does the money go?

Time to design new blocks and full answers, keep icons and docs up to date, and run the site.

Who can sponsor?

Developer tools, learning platforms, hiring teams and anyone building for engineers. We say no to gambling, crypto schemes and anything misleading.

Does a logo go inside the library file?

No. The library file stays clean. Logos appear on this site and in the GitHub README.
